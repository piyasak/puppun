# คู่มือผู้ใช้ Pilot — punpun (staging)

คู่มือนี้ใช้กับเว็บทดสอบ https://punpun-staging.onrender.com ข้อมูลในช่วง Pilot อาจถูกล้างได้ และ**ยังไม่มีการเก็บเงินจริง**

## ก่อนเริ่ม
- PC ที่ใช้ Windows 10 หรือ 11 (64-bit) และมีที่ว่างในไดรฟ์ที่จะเก็บคลิปอย่างน้อย 5 GB
- โทรศัพท์ Android, สาย USB ที่ส่งข้อมูลได้ (ไม่ใช่สายชาร์จอย่างเดียว) และแอป TikTok ที่ login บัญชีที่จะโพสต์ไว้แล้ว
- วิดีโอที่คุณมีสิทธิ์ใช้ จะเป็นลิงก์ YouTube / Bilibili หรือไฟล์บนเครื่องก็ได้
- เวลาประมาณ 20 นาที ช่วยจดเวลาเริ่มไว้ด้วย เพราะเราวัดว่าเริ่มใช้งานได้ภายใน 20 นาทีหรือไม่

## ขั้นตอน
1. **สมัครสมาชิก** ที่ https://punpun-staging.onrender.com/signup แล้วกดลิงก์ยืนยันในอีเมล
2. **ตั้งค่าบัญชี** ด้วยชื่อผู้ใช้และชื่อ Workspace แล้วยอมรับคำรับรองสิทธิ์ในเนื้อหา คุณจะได้แพ็กเกจทดลองใช้
3. **สร้าง Environment** ที่เมนู **Environments** แล้วตั้งชื่อ เช่น "บ้าน" หรือ "ออฟฟิศ" (ต้องสร้างก่อนจึงจะได้รหัสเชื่อมต่อ)
4. **ติดตั้ง Agent** โดยไปที่เมนู **Agent** แล้วกด **ดาวน์โหลด Agent**
   - (ไม่บังคับ) ตรวจไฟล์ด้วย `Get-FileHash <ไฟล์> -Algorithm SHA256` ใน PowerShell แล้วเทียบกับค่าที่หน้า Agent แสดง
   - ดับเบิลคลิกไฟล์ ถ้า Windows ขึ้น "Windows protected your PC" ให้กด **More info → Run anyway**
5. **เชื่อม Agent กับบัญชี**: หน้าต่าง "ตั้งค่า punpun Agent" จะเปิดขึ้น
   - กลับมาที่หน้า **Agent** บนเว็บ กด **สร้างรหัสเชื่อมต่อ** แล้วพิมพ์รหัสในหน้าต่างนั้นภายในเวลาที่เว็บบอก
   - เลือกโฟลเดอร์เก็บคลิปในไดรฟ์ที่ว่างมาก เช่น `D:\punpun\clips` และเลือกโฟลเดอร์วิดีโอของคุณ
   - กด **บันทึกและเริ่มทำงาน** แล้วเปิดหน้าต่าง Agent ทิ้งไว้
6. **ต่อโทรศัพท์**
   - เปิด **ตัวเลือกสำหรับนักพัฒนา** โดยไปที่ การตั้งค่า → เกี่ยวกับโทรศัพท์ แล้วแตะ "หมายเลขบิลด์" (หรือ "เวอร์ชัน MIUI / HyperOS") 7 ครั้ง
   - เปิด **USB debugging** ในตัวเลือกสำหรับนักพัฒนา
   - เสียบสาย USB เข้ากับ PC แล้วกด **อนุญาต** ที่หน้าจอโทรศัพท์
   - เมนู **โทรศัพท์** บนเว็บจะแสดงเครื่องภายในประมาณ 1 นาที ใส่ชื่อบัญชี TikTok ที่เครื่องนี้ใช้โพสต์ด้วย
7. **สร้างงานแรก** ที่เมนู **สร้างงาน** เลือกแหล่งที่มา 1 ใน 3 แบบ แล้วกดถัดไปจนกด **สร้างงาน**
   - **ลิงก์ YouTube / Bilibili:** Agent ดาวน์โหลดแล้วตัดคลิปให้
   - **วิดีโอเต็มบนเครื่อง Agent:** วางไฟล์ไว้ตรงในโฟลเดอร์วิดีโอ แล้วเลือกจากรายการบนเว็บ Agent ตัดคลิปให้ ใช้เวลาประมาณ 0.6–0.8 เท่าของความยาวคลิป
   - **คลิปที่ตัดแล้ว (เรียงตาม EP):** สร้างโฟลเดอร์ย่อยในโฟลเดอร์วิดีโอ เช่น `เรื่องA\EP01.mp4, EP02.mp4` แล้วเลือกโฟลเดอร์บนเว็บ Agent ส่งทุกไฟล์ .mp4 ขึ้นมาตามลำดับตอนพร้อมภาพตัวอย่าง ไม่ตัดหรือแก้ไฟล์
   - รายการบนเว็บอัปเดตทุกประมาณ 1 นาที ต้องใช้ Agent 0.5.0 ขึ้นไป
8. **ตรวจและอนุมัติคลิป** ในหน้างาน ดูภาพตัวอย่าง แก้แคปชันหรือแฮชแท็กได้ แล้วกด **อนุมัติ**
9. **ตั้งเวลาโพสต์** โดยเลือกโทรศัพท์ เวลาเริ่ม ระยะห่าง และช่วงเวลาที่ให้โพสต์
   - ในช่วง Pilot ระบบ**หยุดก่อนกดโพสต์เสมอ** (dry run) ยังไม่โพสต์จริง จนกว่าทีมงานจะแจ้งว่าเปิดให้โพสต์จริงสำหรับบัญชีของคุณ

## เมื่อมีปัญหา
แจ้งทีมงานพร้อมข้อมูลเหล่านี้:
- ขั้นตอนที่ติด และข้อความที่ขึ้นบนจอ (แคปหน้าจอได้ยิ่งดี)
- เวลาที่เกิด
- ชื่อผู้ใช้ punpun (**ห้ามส่งรหัสผ่านหรือรหัสเชื่อมต่อ**)

ปัญหาที่พบบ่อย:

| อาการ | วิธีแก้ |
|---|---|
| ไม่มีปุ่มสร้างรหัสเชื่อมต่อ | สร้าง Environment ก่อน (ขั้นที่ 3) |
| รหัสหมดอายุ | กดสร้างรหัสใหม่ แล้วพิมพ์ให้ทันเวลา |
| โทรศัพท์ขึ้น "ยังไม่อนุญาต USB debugging" | ปลดล็อกโทรศัพท์ แล้วกด "อนุญาต" ที่หน้าจอ |
| โทรศัพท์ไม่ขึ้นเลย | เปลี่ยนสาย USB หรือพอร์ต และตรวจว่าเปิด USB debugging แล้ว |
| Agent ไม่รับงาน | ตรวจว่าหน้าต่าง Agent เปิดอยู่ และไดรฟ์ที่เก็บคลิปว่างอย่างน้อย 5 GB |
| ไม่พบไฟล์วิดีโอ | ไฟล์ต้องอยู่ในโฟลเดอร์วิดีโอที่ตั้งใน Agent และชื่อต้องตรงกัน |
